Short animated explainer videos about real, recent stories: the things most people don't know, told in about a minute with hand-drawn characters in a 3D world.

What Toon Studio is

Toon Studio is the private tool the channel's owner uses to publish those videos. It runs on the owner's own computer and is used only by the owner, for the owner's own YouTube channel. It is not offered to anyone else.

With the owner's permission (Google sign-in), it uses the YouTube API Services to:

  • upload the channel's finished videos with their title, description, tags and cover;
  • post one comment from the channel under each of its own videos;
  • read the channel's own view counts and analytics, so the owner can see which videos work.
